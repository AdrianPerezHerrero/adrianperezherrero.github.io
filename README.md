# Adrián Pérez Herrero — GitHub Pages

This repository contains the source for my personal academic website.

## Publish with GitHub Pages

1. Create a GitHub repository named exactly:

   `AdrianPerezHerrero.github.io`

2. Upload/push the contents of this folder to the repository root.

3. On GitHub, open:
   **Settings → Pages**

4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`

5. Save.

The site should appear at:

`https://adrianperezherrero.github.io/`

## Repository structure

- `index.html` — main site content
- `style.css` — responsive visual styling
- `script.js` — small dynamic behaviour
- `assets/CV_Adrian_Perez_Herrero.pdf` — downloadable CV

Check/update:
